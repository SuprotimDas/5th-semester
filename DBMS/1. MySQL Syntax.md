# Phase 0: MINIMUM DATABASE FOUNDATION

## 1. WHAT IS A DATABASE, DBMS AND RDBMS?

- **Database:** An organized collection of structured data stored electronically in a computer system so that it can be easily accessed, managed, and updated.
- **DBMS (Database Management System):** Software that interacts with users, applications, and the database itself to access, manage and update the data.
- **RDBMS (Relational Database Management System):** A specific type of DBMS that stores data in structured tables composed of rows and columns, establishing logical relationships between different tables.
- **MySQL:** One of the world's most popular open-source RDBMS engines, widely used in web development and enterprise software to handle SQL-based data operations.

## 2. RELATIONAL DATABASE BASICS

- **Database:** A container that stores related data.
    
- **Table:** Data organized into rows and columns.
    
- **Row (or record):** One complete record in a table.
    
- **Column (or field):** An attribute/property of the data.
    
- **Cell:** A single value at the intersection of a row and column.
       
- **Schema:** The structure/design of a database, including tables, columns, data types, and relationships.

## 3. BASIC SQL TERMINOLOGY(just for knowledge)

- **SQL (Structured Query Language):** The standard domain-specific language used to communicate with and manipulate relational databases.
    
- **Query:** Any request sent to a database to retrieve, filter, or manipulate data (commonly associated with `SELECT` commands).
    
- **Statement:** A complete, executable unit of SQL code terminated by a semicolon (e.g., `SELECT * FROM users WHERE user_id = 1;`).
    
- **Clause:** A built-in component of a statement used to filter or modify actions (e.g., `SELECT`, `FROM`, `WHERE`, `ORDER BY`).
    
- **Keyword:** Reserved words in SQL that carry specific structural meanings (e.g., `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `JOIN`).
    
- **Operator:** Symbols or keywords used to perform operations on expressions (e.g., `=`, `>`, `<`, `AND`, `OR`, `LIKE`).
    
- **Expression:** A combination of values, columns, operators, or functions that evaluates to a single value (e.g., `balance + 50` or `age >= 18`).

# Phase 1: Database and Table syntax

## 1. Database Syntax

```sql
-- 1. Create a new database named 'ecommerce'
CREATE DATABASE IF NOT EXISTS ecommerce;

-- 2. View all databases to verify creation
SHOW DATABASES;

-- 3. Set 'ecommerce' as the active database
USE ecommerce;

-- 4. Verify which database is currently active (Outputs: 'ecommerce')
SELECT DATABASE();

-- 5. Delete the database permanently when finished
DROP DATABASE IF EXISTS ecommerce;
```

- **`CREATE DATABASE`:** Creates a new top-level database container on the server.
    
    - _Syntax:_ `CREATE DATABASE database_name;`
    - _Safe variant:_ `CREATE DATABASE IF NOT EXISTS database_name;` (prevents errors if the database already exists).
        
- **`SHOW DATABASES`:** Lists all existing databases on the database server that your current user account has permission to view.
    
    - _Syntax:_ `SHOW DATABASES;`
    
- **`USE`:** Selects and sets an active database for your current session, so you don't have to specify the database name in subsequent queries.
    
    - _Syntax:_ `USE database_name;`
        
- **`SELECT DATABASE()`:** A utility function that returns the name of the currently active (selected) database for your active session. Returns `NULL` if no database is selected.
    
    - _Syntax:_ `SELECT DATABASE();`
        
- **`DROP DATABASE`:** Permanently deletes an existing database, along with all of its tables, schemas, and stored data. **This action cannot be undone.**
    
    - _Syntax:_ `DROP DATABASE database_name;`
        
    - _Safe variant:_ `DROP DATABASE IF EXISTS database_name;` (prevents errors if the database does not exist).

## 2. Table Syntax

```sql
-- 1. Create a users table
CREATE TABLE users (
    user_id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100)
);

-- 2. View all tables in the database
SHOW TABLES;

-- 3. Check the column structure of the table
DESCRIBE users;

-- 4. Add a new column to the table
ALTER TABLE users ADD age INT;

-- 5. Rename the table
RENAME TABLE users TO registered_users;

-- 6. Wipe all data inside the table (keeps structure)
TRUNCATE TABLE registered_users;

-- 7. Permanently delete the table structure and data
DROP TABLE IF EXISTS registered_users;
```

- **`CREATE TABLE`:** Defines and creates a new table structure with specified column names, data types, and constraints (like `PRIMARY KEY` or `NOT NULL`).
    
    - _Syntax:_ `CREATE TABLE table_name (column1 datatype constraints, column2 datatype constraints);`
        
- **`SHOW TABLES`:** Displays a list of all tables in the currently active database.
    
    - _Syntax:_ `SHOW TABLES;`
        
- **`DESCRIBE` / `DESC`:** Displays the schema details of a table, including column names, data types, nullability, keys, and default values.
    
    - _Syntax:_ `DESCRIBE table_name;` or `DESC table_name;`
        
- **`SHOW CREATE TABLE`:** Generates the exact `CREATE TABLE` SQL statement used to build the specified table, including all engine settings and constraints.
    
    - _Syntax:_ `SHOW CREATE TABLE table_name;`
        
- **`ALTER TABLE`:** Modifies an existing table's structure—such as adding, dropping, or renaming columns and modifying data types.
    
    - _Syntax:_ `ALTER TABLE table_name ADD column_name datatype;`
        
- **`RENAME TABLE`:** Changes the name of an existing table to a new name.
    
    - _Syntax:_ `RENAME TABLE old_name TO new_name;`
        
- **`TRUNCATE TABLE`:** Removes **all rows** from a table instantly while keeping the table structure intact. It is faster than `DELETE` because it resets auto-increment counters and bypasses row-by-row deletion logging.
    
    - _Syntax:_ `TRUNCATE TABLE table_name;`
        
- **`DROP TABLE`:** Permanently deletes the entire table—both its data and its structure—from the database.
    
    - _Syntax:_ `DROP TABLE table_name;`

# Phase 2: CONSTRAINTS & DATA MANIPULATION

### 1. CONSTRAINTS

Constraints are rules enforced on data columns to ensure accuracy, reliability, and integrity within a table.

- **`PRIMARY KEY`:** Uniquely identifies each record in a table. Must contain unique values and cannot contain `NULL` values. A table can have only one primary key.
    
- **`NOT NULL`:** Ensures that a column cannot store a `NULL` (empty/missing) value; a value must be provided for every row.
    
- **`UNIQUE`:** Guarantees that all values in a column (or set of columns) are distinct from one another. Unlike primary keys, `UNIQUE` columns allow `NULL` values.
    
- **`DEFAULT`:** Assigns a default fallback value for a column if no explicit value is specified during insertion.
    
- **`CHECK`:** Ensures that all values in a column satisfy a specific logical condition (e.g., `age >= 18`).
    
- **`AUTO_INCREMENT`:** Automatically generates a sequential integer for new records (commonly used for primary keys).
    
- **`FOREIGN KEY`:** Maintains referential integrity by linking a column in one table to the `PRIMARY KEY` of another table, preventing orphaned records.
    

```
-- Example table incorporating Phase 2 constraints
CREATE TABLE users (
    user_id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    age INT CHECK (age >= 18),
    status VARCHAR(20) DEFAULT 'active'
);
```

## 2. INSERT

Used to add new records into a table.

- **`INSERT INTO`:** The foundational clause that targets a specific table and defines column destinations.
    
- **Single Row Insertion:** Inserts one record at a time.
    
    ```
    INSERT INTO users (username, age) 
    VALUES ('alice', 25);
    ```
    
- **Multiple Rows Insertion:** Adds multiple records in a single execution for better performance.
    
    ```
    INSERT INTO users (username, age) 
    VALUES 
        ('bob', 30),
        ('charlie', 22),
        ('david', 40);
    ```
    
- **`INSERT ... SELECT`:** Copies rows from one table and inserts them directly into another table.
    
    ```
    INSERT INTO archived_users (user_id, username)
    SELECT user_id, username FROM users WHERE age > 35;
    ```
## 3. UPDATE

Modifies existing records in a table.

- **`UPDATE`:** Specifies the target table to modify.
    
- **`SET`:** Specifies the columns and their new target values.
    
- **`UPDATE` with `WHERE`:** Filters which specific rows will be updated. **Crucial:** Omitting the `WHERE` clause updates every single row in the table.
    
- **Multiple Column Updates:** Updates more than one column simultaneously in a single statement.

    ```
    -- Updating multiple columns for a single filtered row
    UPDATE users 
    SET age = 26, status = 'premium' 
    WHERE username = 'alice';
    ```
## 4. DELETE

Removes existing records from a table.

- **`DELETE FROM`:** Identifies the source table from which rows will be removed.
    
- **`DELETE` with `WHERE`:** Target-deletes specific rows meeting a criteria. **Warning:** Omitting `WHERE` clears all rows in the table.
    
- **Deleting Multiple Rows:** Uses logical operators within `WHERE` to drop subsets of records.    
    ```
    -- Deleting multiple records matching a condition
    DELETE FROM users 
    WHERE age < 20 OR status = 'inactive';
    ```
